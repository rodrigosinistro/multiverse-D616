# Migração 0.1.69

Esta versão não altera dados de Actors, Items, Combats ou compêndios.

A mudança corrige a montagem da fórmula de Powers e armas no Foundry VTT v14. O sistema passa a combinar, no momento da rolagem, `system.formula` com o atributo selecionado no Item. Nenhuma migração de Items existentes é necessária.

Para instalação manual, feche o Foundry VTT, substitua integralmente a pasta `Data/systems/multiverse-d616` e abra o mundo novamente.
